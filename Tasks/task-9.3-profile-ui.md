# Task 9.3 — Build the profile editor and integrate chat avatars

**Section:** 9. User Profile & Status
**Status:** ✅ Completed

## WHAT
Add an accessible profile editor to the chat account area and use profile photos in avatar surfaces.

## WHY
Users need an obvious place to view and edit their account details, status, and picture.

## HOW
- Open the profile dialog from the signed-in account in the chat sidebar.
- Show name, read-only email, nickname, mobile number, profile picture, and an editable 139-character status.
- Support uploading and clearing a picture, show validation and server errors, and preserve the default initial avatar.
- Display persisted pictures in the account footer, direct-conversation list/header, new-conversation list, and message avatars.

## BENEFIT
Profile and status features are part of the existing chat experience rather than a disconnected page.
