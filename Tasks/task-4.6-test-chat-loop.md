# Task 4.6 — Test the chat loop

**Section:** 4. Real-Time Messaging Slice
**Status:** ⬜ Not started

## WHAT
Open two browser tabs, log in as two different users, and exchange a message.

## WHY
Verifies end-to-end realtime delivery.

## HOW
- Create two users (register or seed)
- Create a conversation between them
- Send a message from one tab and confirm it appears in the other

## BENEFIT
Students get a visible, working feature that motivates the next steps.
